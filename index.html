About

AARU Chatbot is a free, open-source chatbot template built with Next.js and the Vercel AI SDK. Ship a production-ready AI chatbot in minutes — not months.

Made by AARUTO

Preview

Features

Next.js 15 App Router

Advanced routing, React Server Components, and Server Actions for optimal performance.

Vercel AI SDK

Unified API for text generation, structured objects, and tool calls with LLMs.

shadcn/ui + Tailwind

Beautiful, accessible component primitives with utility-first styling.

Generative UI

Dynamic interfaces generated from AI responses in real-time.

Chat History

Persistent conversations stored in Neon Serverless Postgres.

Auth & File Upload

Auth.js authentication with Vercel Blob for file storage.

Quick Start

# Install Vercel CLI npm i -g vercel # Clone and setup git clone https://github.com/AARUTO347/AARU_CHAT-BOT.git cd AARU_CHAT-BOT vercel link vercel env pull # Install and run pnpm install pnpm db:migrate pnpm dev

Visit http://localhost:3000
